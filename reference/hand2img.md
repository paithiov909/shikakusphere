# Plot a player's hand as an image

This function is a short hand for `paistr(pai) |> plot()`

## Usage

``` r
hand2img(pai, ...)
```

## Arguments

- pai:

  A character vector.

- ...:

  Other arguments passed to
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html).
