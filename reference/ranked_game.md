# Sample data of mahjong game log

Sample data of mahjong game log

## Usage

``` r
ranked_game
```

## Format

An object of class `list` of length 3.

## Source

<https://github.com/Equim-chan/mjai-reviewer/blob/master/convlog/tests/testdata/ranked_game.json>

## Details

A named list that contains sample data of mahjong game log. The data was
coverted from 'tenhou.net/6' format using `read_tenhou6()` function in
[convlog](https://github.com/paithiov909/convlog) package.
