# shikakusphere: Miscellaneous Functions for Japanese Mahjong

A collection of miscellaneous functions for Japanese mahjong that wraps
C++ sources of 'shanten-number'
<https://github.com/tomohxx/shanten-number> and 'cmajiang'
<https://github.com/TadaoYamaoka/cmajiang>.
